# HallJoy 1.6.4

- Added support for the original full-size SteelSeries Apex Pro, plus experimental support for the original Apex Pro TKL and full-size Apex Pro Gen 3 (firmware 4.16.8).
- Confirmed EPOMAKER HE108 support and added seven EPOMAKER keyboard layouts with automatic selection.
- Fixed repeated Apex Pro restarts during keyboard discovery and unnecessary UAP restarts on unrelated device changes.
- Improved startup conflict warnings for RongYuan / ATTACK SHARK keyboard interfaces and connection diagnostics.
