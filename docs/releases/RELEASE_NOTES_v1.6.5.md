# HallJoy 1.6.5

- Added MCHOSE Mix 87 III support (firmware 1.22), with analog mode enabled automatically and disabled on pause or exit.
- Added minimize-to-tray and close-to-tray settings, plus tray controls for Pause/Resume and Input Overlay. The tray icon now indicates when HallJoy is paused.
- Improved reopening an already-running instance and reduced unnecessary UI work while the window is minimized or hidden.
- Removed manual polling-rate and UI-refresh controls; HallJoy now manages these automatically.
- Improved layout editor panning performance, moved panning to right-drag, and removed excess spacing in Configuration and Gamepad Tester.
- Added Open log to keyboard support notices and improved diagnostics across all native protocols, including detection of incomplete reports.
- Added a built-in license viewer and updated dependency packaging.
